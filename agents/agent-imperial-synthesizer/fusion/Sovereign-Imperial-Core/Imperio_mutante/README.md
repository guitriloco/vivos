# Projeto FUSAO_EXTREMA

Este é um projeto avançado de fusão entre inteligências artificiais, especialmente Claude e Gemini, com foco em sinergia e complementariedade entre diferentes modelos de IA.

## Estrutura do Projeto

```
FUSAO_EXTREMA/
├── core.py                 # O Cérebro (Motor Gemini + Lógica Central)
├── .env                    # O Cofre (API Keys e Credenciais)
├── requirements.txt        # Arsenal de Dependências (Pip install)
│
├── arsenal/                # SCRIPTS DE ATAQUE & EXTRAÇÃO
│   ├── scrapers/           # Varredura de leads e dados brutos
│   ├── automations/        # Selenium/Playwright (Navegação Humanoide)
│   └── bypass/             # Gestão de Proxies (SOCKS5) e User-Agents
│
├── entidades/              # O PANTEÃO (Personalidades 01-15)
│   ├── prompts/            # Arquivos .txt/.json com as diretrizes
│   └── memory/             # Contexto específico de cada entidade
│
├── data_lake/              # O RESERVATÓRIO (Onde os 900GB residem)
│   ├── raw/                # Dados brutos recém-extraídos
│   ├── processed/          # Dados refinados e limpos pelo /CARRASCO
│   └── database/           # SQLite ou JSON estruturado para consulta rápida
│
├── ativos/                 # MERCADO DE LUXO (Produção Final)
│   ├── ebooks/             # PLRs mutados e formatados
│   ├── media/              # Imagens (Cyber-Luxury) e Áudios (Phonk/Trap)
│   └── saas/               # Binários ou scripts de Micro-Automação
│
├── brain/                  # SEGUNDO CÉREBRO (Conexão Obsidian)
│   ├── notes/              # Logs de insights e estratégias táticas
│   └── templates/          # Padrões de escrita Corporate Streetwear
│
├── logs/                   # RASTRO OPERACIONAL
│   ├── errors/             # Falhas de conexão ou bloqueios
│   └── results/            # Relatórios de lucro e conversão
│
└── temp/                   # ZONA DE DESCARTE (Arquivos voláteis)
```

## Componentes Principais

### Core
- `core.py`: O cérebro do sistema, contendo a lógica central de interação com a IA
- Sistema de comandos táticos para diferentes funções
- Interface com a API do Gemini

### Arsenal
- Conjunto de ferramentas para automação e extração de dados
- Scripts para interação com a web e manipulação de dados

### Entidades
- Perfis de personalidades de IA com diferentes especializações
- Arquivos de prompts e memória para cada entidade

## Funcionalidades

- Fusão de respostas de diferentes modelos de IA
- Cálculo de sinergia entre respostas
- Classificação automática de tipos de tarefas
- Otimização de prompts por tipo de tarefa
- Sistema de logging avançado

## Como Usar

1. Configure sua chave da API do Gemini no arquivo `.env`
2. Execute `core.py` para iniciar o sistema
3. Use os comandos táticos para diferentes funções

## Comandos Táticos

- `/GOD`: Modo divindade - visão macroscópica e soluções avançadas
- `/SOBERANIA`: Criação de ativos de luxo e controle total de nicho
- `/CARRASCO`: Limpeza de ativos inúteis e rastros digitais
- `/EXPANSSAO_EXTREMA`: Escalabilidade agressiva
- `/RESULTADO_EXTREMO`: Foco em ROI e lucro imediato
- `/MUTAR`: Inovação radical em sistemas legados
- `/SOMBRA`: Auditoria invisível e coleta de inteligência
