# Mutante-Apex-Functions

Repositório de elite consolidando as funções de alta performance do ecossistema Mutante. Focado em portabilidade, eficiência e poder de processamento.

## 🚀 Poderes de Elite

### 1. Núcleo APEX (`apex_core.py`)
- **Hybrid Brain Switching**: Alternância automática entre Gemini (Cloud) e Ollama (Local) baseada em latência e disponibilidade. Garantia de processamento ininterrupto.
- **Apex Telemetry**: Monitoramento de baixo nível de CPU e GPU (NVIDIA), permitindo que o sistema se adapte ao hardware disponível.

### 2. Inteligência de Elite (`elite_intelligence.py`)
- **Chronos Pro**: Motor de predição Monte Carlo otimizado para múltiplos núcleos. Simula milhares de cenários de mercado em segundos para validar a viabilidade de operações.
- **Memory Nexus**: Camada de Memória Ancestral (RAG) ultra-leve usando ChromaDB. Permite que o sistema aprenda com experiências passadas e recupere conhecimento semântico instantaneamente.
- **Stealth Crawler**: Coletor de dados furtivo com rotação de User-Agents e jittering adaptativo para evitar detecção por sistemas anti-bot.

### 3. Defesa de Elite (`elite_defense.py`)
- **Elite Carrasco**: Sistema de Darwinismo Sistêmico. Monitora a eficiência dos processos e purga automaticamente qualquer tarefa que consuma recursos excessivos sem gerar resultados.
- **Stealth Layer**: Ofuscação de rede avançada e fingerprinting dinâmico para comunicações seguras e anônimas.

### 4. Interface Oráculo (`oracle_interface.py`)
- **Telegram C2**: Centro de Comando e Controle via Telegram. Permite monitorar o status do sistema, consultar a memória e disparar processos de pensamento complexos de qualquer lugar.

## 🛠️ Instalação

```bash
pip install -r requirements.txt
```

## 🧠 Configuração

O sistema utiliza variáveis de ambiente para chaves sensíveis:
- `GEMINI_API_KEY`: Chave para o cérebro em nuvem.
- `TELEGRAM_TOKEN`: Token do bot Oráculo.
- `ALLOWED_LIST`: Lista de IDs de usuários autorizados no Telegram.
