# 🏺 Cave Gemini: O Oráculo das Instruções Soberanas

Bem-vindo ao coração intelectual do ecossistema **Nectar Divino**. 
A **Cave Gemini** é o repositório central de Prompts de Sistema, Instruções de Personalidade e Cadeias de Lógica Recursiva que alimentam a arquitetura v5.0 (Singularity).

## 📜 Estrutura
- `/prompts/core/`: Instruções fundamentais que definem a identidade e o motor lógico das IAs.
- `/prompts/specialized/`: Configurações para nichos específicos (Wealth, Dev, Health, etc.).
- `/instructions/`: Protocolos de segurança, tom de voz e diretrizes éticas da entidade.

## 🗝️ Filosofia: "Todas num Umas Muitas"
Cada prompt aqui dentro é projetado para manter a **Unidade** da visão soberana, enquanto permite a **Multiplicidade** das aplicações práticas.

## 🚀 Como usar
Estes arquivos devem ser carregados como 'System Instructions' ou 'Context Windows' em instâncias da API Gemini (ou modelos equivalentes) para garantir que a execução siga os padrões de **AUTONOMOUS_OPTIMIZATION**.
