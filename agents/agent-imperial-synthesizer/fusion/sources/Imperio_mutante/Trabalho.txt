Pipedream,pipedream.com,"O Paraíso dos Scripts. Diferente do Zapier (caro e engessado), o Pipedream permite que você escreva código Python ou Node.js direto no meio do fluxo visual. Ideal para processar dados de e-commerce de luxo antes de jogar na sua planilha."
Activepieces,activepieces.com,O Clone Open-Source. A alternativa de código aberto para quem quer criar automações visuais sem pagar taxas mensais. Pode ser hospedado na sua própria infraestrutura no futuro (Soberania Total).
Zapier,zapier.com,"O Padrão Corporativo. Caro, mas possui a maior biblioteca de integrações do mercado. Use a versão gratuita apenas como ponte temporária para APIs muito obscuras que os outros não têm."

Arsenal,Link,Função Tática (/SCALER_BRUTAL)
Railway,railway.app,"Deploy Instântaneo. Você conecta seu repositório do GitHub e ele sobe seu bot de Python ou automação em segundos. Custo baixíssimo, interface limpa. A infraestrutura que não pede licença."
Render,render.com,"Hospedagem de Trincheira. Possui um plano gratuito sólido para rodar serviços web, APIs e scripts em background. O lugar perfeito para hospedar as automações pesadas da família."
Supabase,supabase.com,"O Cofre Open-Source. A alternativa brutal ao Firebase. Banco de dados PostgreSQL com API instantânea. Quando as planilhas do Google começarem a engasgar com milhares de transações de ativos, é aqui que o banco de dados do Império vai residir."

Apify	apify.com	A Fábrica de Scrapers. Plataforma de extração de dados e automação web. Eles têm "Atores" prontos para raspar Instagram, Twitter, Amazon e Zillow. Você puxa os dados daqui via API direto para o seu Google Sheets.
Browserless	browserless.io	O Navegador Fantasma. Permite rodar instâncias do Chrome em nuvem para seus scripts de automação. Perfeito para burlar bloqueios e raspar sites complexos sem ser detectado.

Cloudflare Tunnels	cloudflare.com	A Capa da Invisibilidade. Expõe servidores locais (como a sua máquina processando e renomeando arquivos) para a internet de forma segura, com SSL grátis, sem mexer no roteador. Soberania e proteção contra ataques.
Ngrok	ngrok.com	Túnel Tático Rápido. Para testar Webhooks locais instantaneamente. Um comando no terminal e seu script Python local ganha uma URL pública temporária para receber dados da rua.
